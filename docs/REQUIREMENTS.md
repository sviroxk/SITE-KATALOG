# Требования к SITE KATALOG

Сайт-каталог для фильмов, игр и книг с персональной медиатекой.

## Основные модули
- Каталог фильмов и сериалов
- Каталог видеоигр
- Каталог книг
- Личная библиотека
- Коллекции
- Поиск
- Рейтинги

## Технологии
- Frontend: React/Vue
- Backend: Node.js/Express
- База данных: PostgreSQL
- Внешние API: TMDB, Steam, Google Books
- Аутентификация: JWT
- Хранение файлов: Cloudinary/AWS S3
